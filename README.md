# OpenRayleigh
Online Rayleigh scattering profiles and laser-diagnostic tools.

**Launch the free web application: https://openrayleigh.org**

No installation or registration is required.

OpenRayleigh provides browser-based tools for:
- Tenti S6 and S7 Rayleigh–Brillouin scattering profiles
- Filtered Rayleigh scattering (FRS)
- Forkey-model iodine-cell transmission
- Gaussian laser linewidth and spectral convolution
- VIPA and Fabry–Pérot optical design
- Scientific plots and data export

This repository contains documentation, examples, and issue tracking.
The application source code is not distributed here.
